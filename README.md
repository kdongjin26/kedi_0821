# 3김 프로젝트 : KEDI 참여 행동

제20회 KEDI 데이터 연구 학술대회 연구과제의 회의·검토용 페이지다.
KELS2013 자료로 중·고등학교 시기 참여의식의 발달 궤적이 성인 초기 정치참여를
예측하는지 검증하였다.

김동진(제1저자) · 김재우 · 김명정 &nbsp;|&nbsp; 2026.08.20. 기준

## 구성

좌측 메뉴에서 이동한다.

- **개요** — 계획(연구계획서 PDF), 안내(공모 결과 안내 PDF)
- **분석** — 기술통계, 분석1~5

| | 내용 | 표본 |
|---|---|---:|
| 기술통계 | 원자료 전체 변수 (완전제거 이전) | 7,324 |
| 분석1 | 중1~고3 6시점 선형 성장 | 5,294 |
| 분석2 | 중1~고1 4시점 선형 성장 | 5,634 |
| 분석3 | 고1 분절 이중 기울기 | 5,294 |
| 분석4 | 분석3 + 문·이과 다집단 | 4,595 |
| 분석5 | 참여 유형 4범주 | 4,498 |

## 파일

```
index.html                메뉴 구성 (좌측 사이드바 · 해시 라우팅)
docs/plan.pdf             연구계획서
docs/notice.pdf           공모 결과 안내
reports/descriptives.html 기술통계
reports/analysis1~5.html  분석 보고서
```

각 보고서 HTML은 해당 폴더의 아티팩트 빌더가 `REPORT_final.md`에서 생성한
자체완결 파일이다. 갱신하려면 빌더를 다시 돌린 뒤 `reports/`로 복사한다.

탭마다 주소가 붙어 링크 공유가 된다 — `#/overview/plan`, `#/analysis/3` 등.
