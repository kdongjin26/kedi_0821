# 3김 프로젝트 : KEDI 참여 행동

제20회 KEDI 데이터 연구 학술대회 연구과제의 회의·검토용 페이지다.
KELS2013 자료로 중·고등학교 시기 참여의식의 발달 궤적이 성인 초기 정치참여를
예측하는지 검증하였다.

김동진(제1저자) · 김재우 · 김명정

## 구성

- **개요** — 계획(연구계획서 PDF), 안내(공모 결과 안내 PDF)
- **분석** — 분석1~5 보고서

| | 내용 | 표본 |
|---|---|---:|
| 분석1 | 중1~고3 6시점 선형 성장 | 5,294 |
| 분석2 | 중1~고1 4시점 선형 성장 | 5,634 |
| 분석3 | 고1 분절 이중 기울기 | 5,294 |
| 분석4 | 분석3 + 문·이과 다집단 | 4,595 |
| 분석5 | 참여 유형 4범주 | 4,498 |

## 파일

```
index.html          메뉴·탭 구성
docs/plan.pdf       연구계획서
docs/notice.pdf     공모 결과 안내
reports/analysis*.html   분석 보고서 (자체완결 HTML)
```

보고서 HTML은 각 분석 폴더의 `10_build_artifact.py`(분석5는 `08_`)가
`REPORT_final.md`에서 생성한 산출물이다. 갱신하려면 빌더를 다시 돌린 뒤
`reports/`로 복사한다.
